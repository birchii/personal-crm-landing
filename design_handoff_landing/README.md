# Handoff: Лендинг «Личная CRM»

## Overview
Одностраничный статичный лендинг продукта «Личная CRM». Единственное целевое действие — перейти в приложение. Все кнопки (`Открыть`, `Открыть приложение`, `Начать бесплатно`) ведут на один URL приложения (задать через константу `APP_URL`).

Стек: **Astro + Tailwind CSS 4**, статическая сборка (`output: 'static'`), без клиентских фреймворков. JS на странице не нужен.

## About the Design Files
Файлы в `design/` — **дизайн-референсы в HTML**, а не продакшн-код. Их нужно воссоздать в Astro-компонентах с утилитами Tailwind 4. Открыть: `design/landing-mobile.dc.html` и `design/landing-desktop.dc.html` в браузере (рядом должен лежать `support.js`). Все стили в них инлайновые — это и есть точная спецификация значений.

Исходный текст: `copy/landing-copy.txt`. Тексты в макетах совпадают с ним дословно; добавлены только мелкие надписи-«эйбрау» над заголовками секций (`Проблема`, `Решение`, …, `FAQ`) и пример карточки контакта в hero (Анна Смирнова) — согласовать с заказчиком.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и радиусы финальные — верстать пиксель-в-пиксель.

## Responsive strategy
Один Astro-шаблон, две раскладки:
- `< 768px` (база) — мобильный макет, эталон ширины 390px, горизонтальный паддинг 20px.
- `≥ 1024px` (`lg:`) — десктопный макет, контейнер `max-w-[1200px] mx-auto px-8`.
- 768–1023px — промежуточное: использовать десктопные сетки на `md:` там, где колонки помещаются (сетки описаны через `auto-fit/minmax`, см. ниже), типографика — мобильная или промежуточная на усмотрение.

Мобильный макет нарисован внутри «телефона» со скруглением 36px и тенью — **это рамка превью, в продакшене её нет**: `main` на всю ширину, фон `#07050d`.

```css
@import "tailwindcss";

  --color-muted-2: #b3abc1;     /* текст в малых карточках преимуществ */
  --color-subtle: #8f879e;      /* подписи, номера, футер */
  --color-accent: #c9a6ff;      /* иконки-точки, стрелки, бордер лого */
  --color-accent-label: #b994ff;/* эйбрау над заголовками */

  --color-avatar-ink: #d8c2ff;
  --color-btn-ink: #0b0812;     /* текст на белой кнопке */

```
Полупрозрачные слои (использовать как `bg-white/4` и т.п.):
- Поверхность карточки: `rgba(255,255,255,.04)`, бордер `rgba(255,255,255,.09)`.
- Шапка-кнопка / карточка hero: `rgba(255,255,255,.05–.07)`, бордер `rgba(255,255,255,.10–.12)`.
- Разделители секций: `border-top: 1px solid rgba(255,255,255,.08)`; строки списков `rgba(255,255,255,.10)`.
- Акцентная поверхность: `rgba(185,140,255,.10)`, бордер `rgba(200,160,255,.35)`.

Шрифт: **Onest** (Google Fonts), веса 400/500/600. Подключить через `@fontsource/onest` или `<link>` с `display=swap`. Сглаживание: `-webkit-font-smoothing: antialiased`.

Радиусы: 12–14 (кнопки), 16–18 (FAQ, карточки моб.), 20–24 (карточки десктоп), 28 (карточка решения десктоп), 999 (пилюли).

Тени-свечения:
- Главная кнопка: `0 0 30px rgba(185,140,255,.35)` (моб.) / `0 0 36px rgba(185,140,255,.4)` (деск.); в финальном CTA `.45`.
- Пилюля hero: `0 0 18px rgba(170,110,255,.35)`.
- Белая карточка «Личная CRM»: `0 0 40–44px rgba(185,140,255,.35)`.
- Лого-квадрат: `0 0 12px rgba(185,140,255,.6)`.

## Декоративные элементы (CSS, без картинок)
1. **Точечная сетка**: `background-image: radial-gradient(rgba(255,255,255,.13) 1px, transparent 1.2px); background-size: 18px 18px` (деск. 22px), с маской `mask-image: radial-gradient(ellipse 60% 55% at 50% 40%, #000 30%, transparent 80%)`. Используется в hero, преимуществах (слабее, .10), финальном CTA.
2. **Светящиеся ромбы**: квадрат, `transform: rotate(45deg)`, бордер `1.5px solid rgba(214,180,255,.85)`, фон `radial-gradient(circle at 85% 50%, rgba(200,150,255,.55), rgba(80,40,140,.15) 45%, transparent 70%)` (для правого — `at 15% 50%`), тень `0 0 40px rgba(170,110,255,.5), inset ∓20px 0 50px rgba(220,190,255,.35)`. Пара ромбов выглядывает с краёв экрана.
   - Mobile hero/финал: 300×300, radius 70, `left/right: -250px`, top 210 (hero) / 90 (финал).
   - Desktop hero: 520×520, radius 120, `left/right: calc(50% - 980px)`, top 180. Финал: 460×460, radius 110, `calc(50% - 900px)`, top 40.
   - Одиночный ромб справа в «Решении» (опасити .7/.45/.4): моб. 300px `right:-230px top:40px`; деск. 480px `right: calc(50% - 1020px) top:60px`.
   Секции с ромбами — `relative overflow-hidden`; ромбы `aria-hidden`, `pointer-events-none`.

## Секции (по порядку)
1. **Hero** — моб. высота 844px (в продакшене `min-h-svh` с потолком ~900), деск. `min-h-[900px]`. Шапка: лого (квадрат 22/24px, бордер 1.5 #c9a6ff, radius 7/8 + «Личная CRM» 17/19px 600) и кнопка-призрак «Открыть» / «Открыть приложение». Центр: пилюля («Бесплатно» в подложке + «Работает в браузере»), H1, лид, белая кнопка «Начать бесплатно ↗», подпись. Отступ шапка→пилюля 92/110px, gap колонки 22/26px. Внизу прижата карточка-пример контакта (верх скруглён 20/24px, без нижнего бордера): аватар 40/46 «АС», имя, «Познакомились на конференции», плашка «Обещала прислать контакт дизайнера». На десктопе карточка max-w 640, элементы в строку.
2. **Проблема** — паддинг 88/72 (моб.) · 120 (деск.). Эйбрау + «Знакомо?». 4 карточки с номером 01–04. Моб.: столбик, номер слева. Деск.: `grid auto-fit minmax(260px,1fr)` → 4 в ряд, номер сверху (gap 28). Вывод: первая фраза белая, вторая #8f879e.
3. **Решение** — моб. столбик, деск. 2 колонки (`minmax(420px,1fr)`, gap 64, center). Карточка «Что есть в карточке»: градиент `linear-gradient(180deg, rgba(255,255,255,.07), rgba(255,255,255,.03))`, бордер `rgba(200,160,255,.3)`, 4 строки с точкой 8px (#c9a6ff, glow) и разделителями.
4. **Как это работает** — 3 шага. Плитка-номер 44/52px, radius 14/16, бордер 1.5 светлый фиолетовый; шаг 3 — белая плитка. Моб.: вертикальный таймлайн с линией-градиентом между плитками. Деск.: 3 колонки, горизонтальная линия справа от номера.
5. **Преимущества** — заголовок по центру. «Просто» — широкая акцентная карточка на всю ширину (деск.: заголовок 32px слева, текст справа). Остальные 4: моб. сетка 2×2, деск. `auto-fit minmax(260px,1fr)` → 4 в ряд.
6. **Для кого** — список из 4 строк со стрелкой ↗ (#c9a6ff) и разделителями сверху/снизу. Деск.: 2 колонки (заголовок слева, список справа).
7. **Чем отличается** — 3 карточки-контура (заголовок #8f879e, текст #c8c2d4) + 4-я белая «Личная CRM» с glow. Моб. столбик, деск. 4 в ряд. Текст в карточках — исходные фразы без префикса «X —».
8. **Вопросы и ответы** — нативные `<details>/<summary>`, первый открыт (`open`). Маркер скрыт (`list-style:none` + `::-webkit-details-marker{display:none}`), справа кружок 28/32px с «+», при `[open]` поворот на 45° (`transition: transform .2s`). Деск.: 2 колонки (заголовок слева, `align-items:start`).
9. **Финальный призыв** — паддинг 120/110 (моб.) · 160 (деск.), сетка + пара ромбов, H2, текст (max-w 300/500), кнопка «Начать бесплатно ↗», подпись.
10. **Подвал** — лого 18/20px + строка «Чтобы не терять людей и контекст общения с ними.» Моб. столбик, деск. в строку `justify-between`.

## Interactions & Behavior
- Все CTA — обычные `<a href={APP_URL}>`. Hover: `opacity .9` (можно усилить свечение кнопки). Добавить видимый `focus-visible` outline (`#c9a6ff`, 2px, offset 3px).
- FAQ — без JS, нативный `<details>`.
- Анимаций нет. Состояния, данных, форм нет.
