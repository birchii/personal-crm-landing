# Лендинг «Личная CRM»

Одностраничный сайт личной CRM. Все кнопки ведут в приложение: https://app.projectcrm.space

Сделан на Astro и Tailwind CSS 4. Статичная страница: без сервера и базы данных.

## Как запустить у себя

Нужны Node.js 22+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте в браузере адрес, который покажет команда (обычно http://localhost:4321).

## Как собрать

```bash
pnpm build
```

Готовый сайт появится в папке `dist/`. Посмотреть собранную версию: `pnpm preview`.

## Где что лежит

- `src/content/landing.ts` — все тексты страницы и адрес приложения
- `src/sections/` — блоки страницы по порядку
- `src/styles/tokens.css` — цвета, шрифты, размеры
- `design_handoff_landing/` — макеты и описание дизайна
